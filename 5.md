# TCP/IP Model

It contains only 5 layers 

```mermaid
graph TD
    L1["Layer 1: Application"]
    L1 --> L2["Layer 2: Transport"]
    L2 --> L3["Layer 3: Network"]
    L3 --> L4["Layer 4: Data link"]
    L4 --> L5["Layer 5: Physical"]

```
TCP is used in,
• World Wide Web (HTTP/HTTPS)
• Email (SMTP, IMAP, POP3)
• File Transfers (FTP)

## Application Layer

This is where users mostly interact with it like using browser, texting in whatsapp etc .. which lies in our devices. HTTP is used in this layer

```mermaid
graph LR
    Client -->|request| Server
    Server -->|response| Client
```

## Transport Layer

TCP is used in Transport layer. The Transport Layer passes data between the Application Layer and the network Layer.

```mermaid
graph TD
   
    %% Detailed Process Flow
    SubYou["You"] --> Box1[Box / Application]
    Box1 -->|Passes data| TransYou[CC in your country <br/> Transport Layer]
    
    TransYou --> Network[Network]

    Network --> TransFriend[CC of another country <br/> Transport Layer]
    TransFriend --> Box2[Box / Application]
    Box2 --> Friend2[Friend]

    %% Styling connections
    Box1 -.->|Transport actions| TransYou
    TransFriend -.->|Transport actions| Box2
```
