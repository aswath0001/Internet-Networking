# TCP/IP Model

It contains only 5 layers 

```mermaid
graph TD
    L1["Layer 1: Application"]
    L1 --> L2["Layer 2: Transport"]
    L2 --> L3["Layer 3: Network"]
    L3 --> L4["Layer 4: Data link"]
    L4 --> L5["Layer 5: Physical"]

```
TCP is used in,
• World Wide Web (HTTP/HTTPS)
• Email (SMTP, IMAP, POP3)
• File Transfers (FTP)

## Application Layer

This is where users mostly interact with it like using browser, texting in whatsapp etc .. which lies in our devices. HTTP is used in this layer

```mermaid
graph LR
    Client -->|request| Server
    Server -->|response| Client
```

## Transport Layer

TCP is used in Transport layer. The Transport Layer passes data between the Application Layer and the network Layer.It is located in our systems itself

```mermaid
flowchart TD
    subgraph Sender["Sender's Device"]
        A["Application Layer"] --> B["Transport Layer"]
        B --> C["Network Layer"]
    end

    C --> D["Network / Internet"]

    subgraph Receiver["Receiver's Device"]
        E["Network Layer"] --> F["Transport Layer"]
        F --> G["Application Layer"]
    end

    D --> E

```
